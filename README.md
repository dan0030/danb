# 花札 — 드림 페어 아카이브 (화투 디자인판)

[dan0030/IF](https://github.com/dan0030/IF)의 드림 페어 아카이브 개인홈을 복제해서, **기능은 그대로 두고 레이아웃과 디자인을 화투패·일본풍으로 새로 짠 버전**입니다.
Cloudflare Workers + D1으로 돌아가요.

## 화투 디자인에서 바뀐 점

- **단색 위주의 깔끔한 화면**: 흰 종이 바탕에 다홍과 먹 두 가지 색만 써요. 그라데이션·그림자 대신 가는 선, 점 무늬, 사선 띠, 윤곽선 영문 글씨로 꾸며요.
- **머리말(상단바) 없음 → 접고 펼치는 메뉴바**
  - 사이트 이름, 페어 이름 상자, 메뉴, 카테고리, 검색, 링크, BGM, 라이트/다크, 글쓰기·관리·로그인이 모두 왼쪽(또는 오른쪽) 메뉴바 하나에 들어가요.
  - PC: 맨 위 버튼으로 메뉴바를 접으면 아이콘 줄만 남고, 아이콘에 마우스를 올리면 이름표가 나와요. 접은 상태는 브라우저에 기억돼요.
  - 휴대폰: 구석의 다홍 버튼을 누르면 메뉴바가 옆에서 밀려 나와요. (관리 › 디자인 › 배치 › 휴대폰 메뉴에서 하단 탭을 함께 켤 수도 있어요)
  - 메뉴바 위치(왼쪽/오른쪽)는 관리 › 디자인 › 배치 › 메뉴바 위치에서 바꿔요.
- **홈 화면: 한 화면에 위젯 블록 쌓기**
  - 스마트폰처럼 옆으로 넘기는 페이지 대신, 한 화면에 위젯을 블록으로 추가하고 아래로 스크롤해요.
  - 위젯 너비는 25% · 33% · 50% · 66% · 75% · 100% 중에서 골라요.
  - 예전에 여러 페이지로 저장한 홈은 페이지 순서대로 한 화면에 이어 붙여 보여줘요.
- **움직임**
  - 페이지를 넘길 때 다홍 막이 사선으로 한 번 스쳐가요.
  - 페이지 제목: 도장과 영문 단어, 위로 떠오르는 제목, 짧은 다홍 마디가 그어지는 가는 선이 차례로 나타나요.
  - 메뉴 줄은 왼쪽 다홍 선이 차오르며 글자가 밀리고, 버튼은 색이 옆으로 차올라요.
  - 위젯은 살짝 떠오르며 다홍 귀퉁이가 접혀 나오고, 목록 사진은 평소엔 다홍 단색이다가 마우스를 올리면 원래 색으로 돌아와요.
  - 스크롤하면 블록이 하나씩 떠올라요. (지원하는 브라우저에서)
- **테마 프리셋**: 紅白 홍백(기본) · 墨 먹 · 紅 베니 · 松 송학 · 藤 등꽃 · 芒 공산명월. 기존 One UI 프리셋도 그대로 있어요.
- **관리 › 디자인 › 효과 · 모드**에서 배경 장식, 페이지 넘김 막, 사진 다홍 효과를 따로 끌 수 있어요. 기기에서 '동작 줄이기'를 켜면 움직이는 장식은 모두 멈춰요.

화투 디자인 파일: `src/styles/hwatu.css`(스타일), `src/components/Shell.jsx`(메뉴바·레이아웃), `src/lib/hwatu.js`(열두 달 패·페이지 글자)

## 원래 있던 기능 (그대로)

- **홈 화면**: 스마트폰 홈 화면처럼 여러 페이지를 옆으로 넘겨 보고, 페이지마다 위젯을 놓습니다. 위젯은 21종입니다. 프로필(페어), 앱 아이콘, 디데이, 시계, 최근 글, 인기글, 공지, 배너, 플레이리스트, 캘린더, 갤러리, 흐르는 갤러리, 투두, 태그, 랜덤 한마디, 메모, HTML, 링크, 사진, 숫자 요약, BGM이 있어요.
- **글쓰기**: 직접 만든 리치 에디터와 HTML 직접 입력을 오가며 쓸 수 있습니다.
  - 서식: 글꼴 30종, 글자 크기와 색, 형광펜
  - 넣기: 사진 업로드·붙여넣기·끌어놓기, 유튜브
  - 블록: 대화(메신저·문자), 대사, 편지지, 메모지, 접은 글, 스포일러, 표 등
  - 이름 변환: 글 속 `{{나}}` `{{상대}}` `{{페어}}`가 프로필 이름으로 바뀌어요.
  - 공개 범위: 공개 / 보호(비밀번호) / 비공개
  - 기록 날짜를 직접 정할 수 있고, 쓰는 중에는 자동으로 임시저장돼요.
- **디자인 편집**:
  - 프리셋 13종
  - 라이트·다크 색 12가지씩
  - 배경: 단색 / 그라데이션 / 패턴 7종 / 이미지
  - 글꼴: 30종, 직접 올린 글꼴도 쓸 수 있어요.
  - 카드 스타일 6종, 모서리, 간격, 너비
  - 큰 제목 / 서랍 / 하단 탭 배치
  - 페이지 점 모양, 목록 모양 5종(리스트·갤러리·메모·카드·타임라인)
  - 사용자 CSS를 넣을 수 있고, 디자인 코드로 복사·붙여넣기도 돼요.
  - 위젯마다 배경과 글자색도 따로 정할 수 있어요.
- **그 밖의 기능**: 카테고리(하위 포함, 카테고리별 목록 모양), 태그, 검색, 캘린더, 공지, 방명록·댓글(비밀글, 답글), 글 반응 이모지, BGM 플레이어, 백업 내보내기·불러오기가 있어요.

## 배포하기 (처음 한 번)

[Node.js](https://nodejs.org) 18 이상과 Cloudflare 계정이 필요합니다.

```bash
npm install
npx wrangler login                     # 브라우저에서 Cloudflare 로그인
npx wrangler secret put ADMIN_PASSWORD # 관리자 비밀번호 입력 (길고 어렵게!)
npm run deploy                         # 빌드 + 배포
```

배포가 끝나면 `https://danb.<내계정>.workers.dev`로 접속할 수 있어요.

- 메뉴의 열쇠 아이콘이나 `/login`에서 로그인하면 글쓰기·관리·홈 편집이 열립니다.
- 원본(IF)과 데이터가 섞이지 않도록 이 저장소는 **따로 만든 D1 데이터베이스(`danb-db`)와 R2 버킷(`danb-files`)**을 써요. 둘 다 이미 만들어져 `wrangler.jsonc`에 연결돼 있고, 테이블은 첫 접속 때 자동으로 만들어져요.
- 원본 사이트의 글을 옮기고 싶으면 원본의 관리 › 백업에서 내보낸 파일을 이 사이트의 관리 › 백업에서 불러오면 돼요.
- 사이트 이름은 `wrangler.jsonc`의 `name`을 바꾸면 달라져요.
- 내 도메인은 Cloudflare 대시보드 > Workers > 설정 > 도메인에서 연결해요.

### GitHub에 올릴 때마다 자동 배포하기 (선택)

Cloudflare 대시보드 > Workers & Pages > **danb** > 설정 > 빌드에서 이 저장소(`dan0030/danb`)를 연결하세요.

- 프로덕션 브랜치: `main` (사이트에는 `main`에 올린 내용만 반영돼요)
- 빌드 명령: `npm run build`
- 배포 명령: `npx wrangler deploy`
- 다른 브랜치에 올릴 때마다 미리보기 빌드가 돌면서 실패로 표시될 수 있어요. 필요 없으면 설정 › 빌드 › **비프로덕션 브랜치 빌드**를 꺼두세요.

`ADMIN_PASSWORD`는 Worker 설정 > 변수 및 비밀에 넣어주세요.

**자동 배포가 멈췄을 때 (Git 연결이 끊어졌다고 나올 때)**

- Cloudflare가 지켜보는 **프로덕션 브랜치가 GitHub에 아직 있는지** 먼저 확인하세요. 연결해 둔 브랜치를 지우거나 이름을 바꾸면(예: 작업 브랜치를 `main`으로 바꾸기) Cloudflare는 더 이상 빌드할 브랜치를 찾지 못해요. 설정 › 빌드 › 브랜치 제어에서 프로덕션 브랜치를 `main`으로 바꾸세요.
- 그래도 '연결 끊김'으로 나오면 설정 › 빌드에서 Git 저장소 연결을 끊었다가 `dan0030/danb`를 다시 연결하세요.
- GitHub › Settings › Applications › **Cloudflare Workers and Pages** › Configure에서 `danb` 저장소에 접근 권한이 있는지도 확인하세요.

### 파일 저장소 (R2)

- **어디에 저장되나:** 글·설정·댓글은 D1(`danb-db`)에, 올린 사진·파일은 R2 버킷 `danb-files`에 저장돼요.
  - R2 무료 범위는 매달 저장 10GB와 업로드 100만 건이고, 파일당 최대 25MB까지 올릴 수 있어요.
  - 예전에 D1에 저장된 파일은 사이트에 요청이 올 때마다 조금씩 R2로 자동으로 옮겨져요.
  - 관리 › 백업 · 파일에서 남은 파일을 한 번에 옮길 수도 있어요.
- **자동 삭제:** 글에서 사진을 빼고 저장하거나, 글·타래를 지우거나, 설정에서 사진을 바꾸면 이렇게 처리돼요.
  - 그 파일을 사이트 어디에서도 더 이상 쓰지 않을 때만 저장소에서 지워요.
  - 다른 글에서 같은 사진을 쓰고 있으면 남겨둬요.
- **직접 정리:** 관리 › 백업 · 파일에서 파일마다 "사용 중 / 안 씀"을 볼 수 있어요.
  - 하나씩 지우거나 "안 쓰는 파일 정리"로 한꺼번에 지울 수 있어요.
  - 한꺼번에 지울 때는 올린 지 하루가 지난 파일만 지워서, 아직 저장하지 않은 글의 사진은 지켜져요.

## 내 컴퓨터에서 실행하기

```bash
cp .dev.vars.example .dev.vars   # 로컬 관리자 비밀번호 설정
npm run dev                      # http://localhost:8787
```

화면만 고칠 때는 `npx wrangler dev`를 켜둔 채 다른 창에서 `npm run dev:ui`를 실행하면 바로바로 새로고침돼요.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `worker/` | Cloudflare Worker: API, 로그인, D1 테이블, 파일 업로드 |
| `src/lib/defaults.js` | 사이트·디자인·홈 화면 기본값, 테마 프리셋, 글꼴 목록 |
| `src/widgets/index.jsx` | 홈 위젯 전부 (새 위젯은 여기 `WIDGETS`에 추가) |
| `src/editor/RichEditor.jsx` | 글쓰기 에디터와 블록 템플릿 |
| `src/admin/` | 관리 화면과 설정 항목 정의 |
| `src/styles/` | 기본 스타일 (색·모양은 전부 CSS 변수) + `hwatu.css` 화투 디자인 층 |
| `src/lib/hwatu.js` | 열두 달 화투패·계절·페이지 한자 |
